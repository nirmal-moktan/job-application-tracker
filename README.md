# Job Application Tracker

A simple Python and SQLite application for tracking job applications.

## Features

- Add new job applications
- View saved applications
- Update application information
- Delete applications
- Validate text, dates, and application status
- Store application data permanently using SQLite

## Application Information

Each job application stores:

- Company
- Job title
- Location
- Application deadline
- Job start date
- Status

## Technologies

- Python
- SQLite
- Git
- GitHub
