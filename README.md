# Job Application Tracker

A full-stack Python, Flas, and SQLite application for tracking job applications.

## Features

- View saved job applications in a web interface
- Update application status directly from the website
- Store application data permanently using SQLite
- Validate text, dates, and application status
- Display application data in a table
- Use dropdown menus for application status

## Application Information

Each job application stores:

- Company
- Job title
- Location
- Applied date
- Status
- Remarks
